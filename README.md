# Nexspace Realty enquiry form

Client enquiry registration (Thai / English). Live at https://nexspace-realty.github.io/enquiry/

Submissions are emailed with a PDF to nathita.t@ and piriya.t@nexspace-realty.com via FormSubmit.
Optional link parameters: ?agent=NAME&from=PLACE&lang=th

## Owner property registration
Owner form (digital version of the paper Property Registration sheet): https://nexspace-realty.github.io/enquiry/owner/
Optional link parameters to pre-fill: ?project=Romm%20Convent&unit=504&type=condo&for=sale,rent&agent=NAME&lang=th
Submissions use the same Apps Script receiver with form "owner" (saved to the "Owner Listings" tab once Code.gs is redeployed).
